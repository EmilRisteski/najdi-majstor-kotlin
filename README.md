НајдиМајстор

НајдиМајстор is an Android application that connects clients with local handymen and service providers. The app allows users to browse handyman profiles, search by service or city, filter results, save favorites, read reviews, and contact handymen through in-app chat.

The application is built as a graduation project and focuses on a simple, practical flow: a client finds a suitable handyman and contacts them directly.

Features
- User registration and login
- Google Sign-In
- Role selection: Client or Handyman
- Client home screen with categories, search, and filters
- Handyman profile creation and editing
- Public handyman listings
- Favorite handymen
- Handyman details screen
- Ratings and reviews
- Review sorting by newest, highest rating, and lowest rating
- In-app text chat
- Local chat notifications
- Profile activation/deactivation for handymen
- Account deletion with Firestore cleanup
- Light and dark mode support
- Macedonian user interface

Filters
- Clients can filter handymen by:
- City
- Availability
- Price range using a snapping slider
- Manual price range fields
- Negotiable price option


Tech Stack
- Kotlin
- Jetpack Compose
- Material 3
- Firebase Authentication
- Cloud Firestore
- Firebase Cloud Messaging
- Android Credential Manager
- Google Sign-In
